# BE1 module boundaries

Coordinator owns schemas/config/main/routes/contracts/dependencies. Agents must read the complete user implementation prompt and role handoff. No TinyFish or external AI. Python 3.12 supported.

Extraction: `extract_document(path: Path, kind: str, input_language: str, settings: Settings, progress: Callable[[dict], None] | None = None) -> dict` synchronous parser, invoked inside `await extract_isolated(...)` in production. The isolated worker has private pipe messages, a hard timeout and memory/process-tree limits. Returns `{clauses: list[Clause], warnings: list[str], input_language: str, document_type: str}`. `ocr_capabilities() -> dict` returns executable availability and language list (including auto-discovered tools/ocr). Raise schemas.ApiError. No session writes. Cancellation terminates the parser tree; liveness/revision is still checked before committing results. Controlled test-only extractor injection may use a thread.

Lifecycle: `SessionStore(settings)` owns `records: dict[str, DocumentRecord]`. Async methods `create(filename, kind, input_language, document_type) -> (record, token)`, `get(document_id, token, touch=True)`, `review(record, ReviewRequest) -> bool changed`, `delete(record) -> list[str] private analysis IDs`, `expire() -> list[list[str]]`, `startup_cleanup()`. Record fields: document_id, token_hash, filename, kind, input_language, document_type, path, revision=1, reviewed_revision=None, status='extracting', clauses=list[Clause], warnings=list[str], extraction_ready=False, extraction_progress=dict, analyses=dict[str,dict], question_cache=dict, deleted=False, lock=asyncio.Lock, expires_at=float wall-clock. `create` allocates private path but upload writer writes bytes. `get` wrong token/unknown/expired => NOT_FOUND. `review` locks, checks revision, blocks active analyses, validates corrections, increments only genuine changes, sets reviewed_revision=current. `delete` tombstones immediately, clears data/files; coordinator propagates all returned IDs. Expiry cleanup returns IDs. `BoundedJobs(workers, queue_size)` in jobs: async `submit(coroutine_factory)`, `close()`. Reject full with MODEL_BUSY. No GPU scheduling.

ML adapter: `RealMLClient(settings, transport=None)` / `FixtureMLClient(settings)`. Async `health()->dict`, `start(payload)->dict`, `poll(analysis_id)->dict`, `question(payload)->dict`, `delete(analysis_id)->None`, `close()`. HTTP errors -> ApiError. `validate_snapshot(snapshot,payload)->dict` checks schemas, identities/progress/coverage/evidence/references/current clause IDs. `validate_answer(answer,payload,result)->dict`. Fixture only explicit, returns labelled literal development echoes, no legal diagnosis. Preserve optional stage/failed_clauses and result fields. No source/session tokens sent to ML. Real token convention proposed X-ML-Service-Token and documented pending BE2 confirmation.

Agent tests: extraction `apps/api/tests/test_extraction.py`; lifecycle `test_lifecycle.py`; ML `test_ml_client.py`. Other tests coordinator. Imports `apps.api.*`. Do not edit shared interfaces without coordinator notification.
